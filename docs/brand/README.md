# Brand

`canon-rodeo-icon.png` is the source icon. `referee/public/icon.png`, `apple-touch-icon.png` and `favicon-32.png`
are generated from it (padded to square, resized).

| Role | Color |
|---|---|
| Midnight (ink, dark background) | `#01132A`, `#010E20` |
| Sunset orange (brand) | `#FD6F16` on dark, `#ED5616` on light |
| Sun gold | `#FDC86D` |

Orange is the brand only. Status colours stay distinct: held/ready green, lost/rejected crimson, pending amber.
